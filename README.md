# RM Flow Browser

RM Flow is an AI-first browser interface demo.

## GitHub Pages

1. Upload these files to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your main branch and `/ (root)`.
5. Save and wait for GitHub Pages to publish.

The demo works as a static website. Real AI responses and full browser-engine features require a backend/API and an Electron/Chromium desktop build.

## Project

- `index.html` — interface
- `style.css` — design
- `script.js` — demo interactions
